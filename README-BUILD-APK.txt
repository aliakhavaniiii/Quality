ساخت APK پروژه Quality Control Management

این بسته شامل سورس اصلی پروژه و گردش‌کار آماده GitHub Actions است.
برای ساخت APK:
1) محتویات ZIP را در یک مخزن GitHub بارگذاری کنید.
2) در GitHub وارد زبانه Actions شوید.
3) گردش‌کار Build Android APK را انتخاب و Run workflow را اجرا کنید.
4) پس از موفقیت، از بخش Artifacts فایل QualityControlManagement-debug-apk را دانلود کنید.
5) فایل ZIP دانلودشده را باز کنید؛ app-debug.apk داخل آن است.

نکته: این خروجی debug برای نصب و آزمایش است و امضای انتشار (release) ندارد.
محیط فعلی ساخت مستقیم APK را ندارد؛ بنابراین در این مرحله APK کامپایل‌شده تولید نشده است.
